# Agent Note：桌面内容位于标题栏控件下方

状态：已实现

[English](2026-09-18-desktop-content-titlebar-safe-area.md) | 中文

## 问题

桌面外壳只预留了 30px，而自定义 Windows 控件占用 38px。因此中心标题和可见的右侧 Sidebar 可能贴住或进入无边框标题栏控件区域。

## 决策

社区桌面主题提供 44px 的标题栏安全区。现有中心列和普通右侧 Sidebar 规则使用该令牌；全屏右侧 Sidebar 仍覆盖整个视口。

## 备选方案

保留 30px 会让第一行内容落入 38px 的无边框控件行内。分别修改布局规则会重复桌面偏移，无法继续使用共享主题令牌。

## 后果

桌面内容会从完整标题栏控件行下方开始，网页构建继续使用自身默认值。当桌面路径能力可用时，工作区和会话的右键菜单继续保留“打开所在位置”。

## 测试

重新构建的 Windows 可执行文件必须进入主界面，中心列和右侧 Sidebar 根节点的 `y` 坐标至少为 44px，并渲染左侧导航的“打开所在位置”右键菜单项。
